1

What's in the package

It's a single .zip file, about 22 MB. Inside is everything needed to regenerate every map and chart in the project from scratch — the underlying data, and two independent sets of scripts (one in Python, one in R) that turn that data into figures.

  • Scripts — the actual instructions that build each figure
  • Data — death records, water station locations, road/desert maps, and a border fencing dataset
  • Written guides — a technical README and methodology notes, for whenever more detail is needed
One thing worth knowing: the border fencing dataset is marked For Official Use Only by the government agency that produced it. Ordinary sensitivity, not classified — but worth a moment's thought before it goes somewhere public.

Sending it to someone

At 22 MB, the zip file is small enough for most ordinary sharing methods — no special tools needed.

MethodWorks?
Email attachmentYes, comfortably under every major provider's limit (typically 25 MB)
Google Drive / Dropbox / OneDriveYes — upload once, share a link
Messaging apps (Slack, iMessage, etc.)Yes, though some compress or reject zip files — a cloud link is safer

Whichever method: send the .zip file exactly as it is. No need to unzip it first.

3

Opening the package

Once the recipient has the .zip file downloaded:

On a Mac

Double-click the file. It unpacks itself into a regular folder, right next to the zip.

On Windows

Right-click the file and choose Extract All, then pick a location.

Tip: put the unpacked folder somewhere easy to find again — the Desktop or Documents both work fine. Everything below assumes you can get back to that folder.
4

Python or R?

Every figure exists twice — once built in Python, once in R — and they produce the same result. Only one is needed. Pick whichever fits:

Choose Python if…

you're comfortable typing commands into a Terminal window, or you just want the more common option.

Choose R if…

you already have (or don't mind installing) RStudio — its setup involves one line, no separate command-line tool.

5a

Setting up Python

Skip to Setting up R if that's the path chosen instead.

Step 1 — Open a Terminal

On a Mac: open Terminal (search for it with Spotlight — Cmd + Space, then type "Terminal"). On Windows: open Command Prompt or PowerShell from the Start menu.

Step 2 — Move into the unpacked folder

Type cd (with a trailing space), drag the unpacked folder from Finder/Explorer straight into the Terminal window, then press Enter.

Step 3 — Set up a private workspace for the required packages

Paste each line below one at a time, pressing Enter after each:

# creates a self-contained workspace inside the folder
python3 -m venv .venv

# installs everything the scripts need into it
./.venv/bin/pip install -r requirements.txt

The second command takes a minute or two — it's downloading several data/mapping libraries.

Step 4 — Run a figure

./.venv/bin/python figure4.py

A line of text will print out, ending with Saved plot to ... — that's success.

5b

Setting up R

Skip this if Python was chosen instead.

Step 1 — Install R and RStudio, if not already installed

Both are free at posit.co/download/rstudio-desktop — install R first, then RStudio.

Step 2 — Open the folder in RStudio

In RStudio: File → Open Folder (or open any of the .R files directly) and point it at the unpacked project folder.

Step 3 — Install one package

In RStudio's Console panel, type this and press Enter:

install.packages("sf")

Step 4 — Run a figure

Open figure4.R in RStudio and click Source (top-right of the editor pane) — or, in the Console, type:

source("figure4.R")
6

Making your first figure

figure4 is the simplest one to try first — a map of recorded deaths before 2008. Once it finishes, a new file called figure4_reproduction.png (or _R.png) appears in the same folder. Open it like any image file.

From there, every other figure works the same way — just swap the number:

FileWhat it shows
figure2The danger index map
figure3All recorded deaths, 2000–2019
figure6 / figure7Hot-spot analysis, before and after the fencing law
figure8Hot spots overlaid on the danger index
7

If something goes wrong

"python3: command not found"

Python isn't installed. Get it from python.org/downloads, then start again from Step 1.

A wall of red text appears

Most of the time the last few lines explain what happened. The single most common cause is a Python version mismatch — this project expects Python 3.9 through 3.12. If a newer version is all that's available, that's worth flagging to whoever put this package together.

The fence lines are missing from a map

Not an error — some figures show a note like fence: OFF in the console if a particular mapping library didn't install. Everything else still renders correctly.

Still stuck

Copy the exact error text and send it back to whoever shared this package — it's almost always a quick fix once the error message is visible.
